# Chinmaya Samantara — Portfolio

My personal portfolio site, built with Next.js, React, TypeScript and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Edit content

All personal details, skills and projects live in [`src/data/resume.tsx`](src/data/resume.tsx).
